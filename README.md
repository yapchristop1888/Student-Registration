# Student Registration System

A simple Student Registration System built using HTML, CSS, and JavaScript. This project allows users to register students by providing their personal and academic information.

## Features

- Add new student records.
- Enter first name, middle name, and last name.
- Enter student email address.
- Select course (BSIS, BSIT, or BSCS).
- Select year level (1st Year to 4th Year).
- Enter student section.
- Display registered students in a table.
- Validate required form fields.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

- index.html – Contains the structure of the registration form and student table.
- styles.css – Handles the design and layout of the system.
- script.js – Handles form submissions and student registration functionality.

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Make sure all project files are in the same directory.
4. Open `index.html` in your web browser.
5. Fill out the registration form and click Add Student.
